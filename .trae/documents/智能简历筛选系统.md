# 摘要
针对企业招聘中简历筛选效率低、主观性强、非标候选人漏判、多格式简历兼容差等痛点，本项目开发了一套对标商业级能力的智能简历筛选系统。系统整合多模态输入处理、轻量级LLM深度语义理解、Transformer+规则引擎混合匹配、三级漏斗筛选等核心技术，实现了对可编辑PDF/Word、扫描件、表格等全格式简历的高效处理（单份≤0.5秒，日处理1万+份）。通过布局感知解析、可迁移能力评分、去偏算法等五大创新点，系统匹配精度达95%以上，人机一致性优于传统筛选方法30%，可直接应用于中小企业社招、校招场景，显著降低HR工作强度，提升招聘效率与公平性。

# 项目目标
开发一个【**智能简历筛选系统**】，主要服务于三个核心角色：招聘方（HR/BOSS）、求职者（候选人）和管理员（Admin）。平台的核心是利用AI技术实现人才与岗位的高效、精准匹配。这是一个智能化的招聘与求职平台，通过自然语言处理、特征向量分析和数据可视化等技术，将传统的简历筛选和岗位匹配过程自动化、智能化。平台为招聘方提供从岗位发布到人才筛选、面试邀请的全流程服务，同时为求职者提供简历优化、岗位推荐和面试辅导等工具，管理员负责模型训练、算法的准确度、运维数据监控等。

# 项目范围
+ 简历文件和JD文件类型：可编辑PDF/Word、扫描件、图片简历、Excel表格简历；
+ 行业类型（5个热门行业）：人工智能、新能源、半导体/芯片、互联网、电子商务；
+ 岗位类型（5个热门岗位）：算法工程师、电池研发工程师、芯片设计工程师、产品经理、跨境电商；
+ 核心功能：
    - 对于管理员角色：
        1. 界面可视化模型训练：
            1. 数据预处理：从指定目录中读取出训练的简历数据和JD数据，进行数据降噪预处理，缺失值处理，异常值处理，数据不一致处理，最后界面点击预处理输出预处理后的结果。
            2. 特征处理：从预处理数据中，提取简历和JD的全部多维实体并界面展示，特征选择准备，转换方法科学有效增强模型的预测能力。
            3. 模型训练：模型训练生成模型数据集，提供给预测使用，要求模型阈值准确高度，可靠性强，错误率低。详细界面输出模型训练的过程数据展示。
            4. 模型评估：针对模型训练结果，量化评估输出准确度，错误率等评估，是否会过拟合和欠拟合等。
        2. 生成训练模型，提供给招聘方和求职者匹配算法时候使用
    - 对于招聘方：
        * 多模态解析：
            + 可编辑PDF/Word：用 PyPDF2 、 python-docx 提取文本，保留原始段落结构；
            + 扫描件/图片简历：用PaddleOCR提取文本，准确率≥92%，处理模糊、倾斜图像时采用图像增强（直方图均衡化）；
            + 表格简历：用 camelot-p  y 提取表格数据，转换为“字段-值”结构化文本（如“学历：本科”）。
        * 文本清洗：
            + 布局感知排序：用 pdfplumber 提取文本块坐标与字体大小，按“标题（大字体）→ 内容（小字体）”“从上到下、从左到右”排序，模拟人类阅读习惯；
            + 文本清洗：去除特殊符号、冗余空行，统一编码为UTF-8，过滤长度≤2的无意义短句；
        * 特征工程：
            + 对简历/JD里面实体自动提取，输出提取的特征信息，要求特征多维和准确
            + 文本特征：用 Sentence-BERT 生成768维向量，用于向量粗筛；
            + 实体特征：通过轻量级LLM提取全部实体：如：姓名,性别,出生日期,年龄,联系电话,电子邮箱,现居地,户籍地,政治面貌,婚姻状况,期望职位,期望行业,期望工作城市,期望薪资,到岗时间,学校名称,学历层次,专业名称,入学时间,毕业时间,是否全日制,GPA/排名/荣誉,公司名称,公司所属行业,在职开始时间,在职结束时间,职位名称,工作地点,工作内容关键词,汇报对象,团队规模,项目名称,项目开始时间,项目结束时间,项目角色,技术栈,项目成果指标,编程语言,框架/工具,数据库,操作系统/平台,语言能力,证书资质,软技能,作品集/个人链接,自我评价关键词,兴趣爱好,总工作经验年限。
            + 格式特征：提取“排版工整度”“成果量化程度”等多模态特征，按0-5分打分；
            + 可迁移能力特征：基于“岗位-能力映射词典”，提取跨界候选人相关技能特征。
        * 匹配筛选（核心）：采用三级漏斗方式，每个过程都输出可视化过程数据
            + 一级向量粗筛：
                - 技术选型： ChromaDB 向量数据库+ Sentence-BERT 模型；
                - 逻辑：将简历与JD转换为768维向量，计算余弦相似度，筛选Top50相关简历（耗时≤0.1秒/份）；
                - 阈值：相似度≥0.5进入下一级，淘汰语义相关性低的简历。
            + 二级规则精筛：
                - 技术选型：JSON规则配置+ jsonpath-ng 解析；
                - 支持算子： in/not_in/gt/lt/eq/contains ，覆盖“学历、工作年限、核心技能”等硬性条件；
                - 逻辑：按企业自定义规则过滤，淘汰80%不符简历，仅保留10份左右进入最终筛选。
            + 三级LLM补筛：
                - 技术选型：支持多种LLM模型，包括qwen-plus、deepseek-chat、moonshot-v1-8k、kimi-k2-turbo-preview、tngtech/tng-r1t-chimera:free、glm-4.6、hunyuan-lite；
                - 核心功能：隐性需求挖掘（如“算法工程师”隐含“数学建模能力”）、空窗期归因、可迁移能力评分；
                - 逻辑：计算软性匹配分，综合判断候选人适配度。
        * 可视化展示：
            1. 雷达图：根据实体特征划分多维度匹配情况
            2. 饼图展示：模型预测结果匹配情况
            3. 通过大模型自动生成：基于简历生成三个对候选人的面试题
            4. 候选人的综合分析：对匹配度和优势和风险分析
    - 对于求职者：
        * 简历制作：在线制作，按照目标填写：
            1. 个人信息
            2. 求职意向
            3. 教育经历
            4. 工作经历
            5. 项目经历
            6. 科研成果
            7. 个人技能
            8. 自我评价
        * 简历解析：llm大模型优化简历
        * 简历画像
        * 岗位筛选：
            + 根据简历自动预测匹配出合适的岗位
            + 岗位列表按照优先级排序
        * 模拟面试：根据面试岗位，自动生成10道面试题
+ 部署环境：支持Windows/Linux系统，兼容CPU（16GB内存）与GPU（≥2GB显存）。

# 模型架构
系统采用“输入层→预处理层→核心筛选层→结果输出层→部署优化层”五级架构，整合多模态处理、深度语义理解、高效筛选等核心技术：

+ 输入层：接收多格式简历与岗位JD输入；
+ 预处理层：完成多模态解析、布局感知排序、文本清洗与去偏处理；
+ 核心筛选层：通过“向量粗筛→规则精筛→LLM补筛”三级漏斗，结合Transformer+LLM+规则引擎实现精准匹配；
+ 结果输出层：生成匹配评分、决策辅助信息与可视化报告；
+ 部署优化层：通过量化、多线程、缓存等技术实现轻量化部署与性能优化。
