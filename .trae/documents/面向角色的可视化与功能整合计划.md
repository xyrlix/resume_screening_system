## 目标

* 将平台功能按角色（**面向招聘方:HR/BOOS**、**面向求职者:intervew **、管理员:admin）整合到 Streamlit 前端，形成清晰的任务流。

* 现重构现有项目，调整项目代码，完善和补齐“智能JD生成、简历优化、岗位推荐、面试题生成、流程监控”等模块，并联动后端权限。

## 现有能力映射

* 后端接口（可直接复用）：

  * 健康与根路由：`scripts/05_api.py:310`、`scripts/05_api.py:315`

  * 匹配与检索：`POST /match`（`scripts/05_api.py:328`）、`POST /filter`（`scripts/05_api.py:345`）、`POST /decision`（`scripts/05_api.py:351`）、`POST /decision_batch`（`scripts/05_api.py:364`）

  * 行业模板与LLM开关：`GET/PUT /config/industry_templates`（`scripts/05_api.py:374`、`scripts/05_api.py:378`）、`POST /config/llm_enabled`（`scripts/05_api.py:408`）

  * 在线采集与平台适配：`POST /ingest_*`（`scripts/05_api.py:383` 起）

  * 上传：`POST /uploads`（`scripts/05_api.py:420`）

* 前端页面（基础）：概览、实体预测、匹配、批量、检索、采集、漏斗、公平性、决策、配置、评估（`scripts/06_visualization.py`）

## 角色视图分组

* HR/BOSS（找人）

  * 输入与来源：

    * JD输入/上传 + 智能JD生成（新增）

    * 简历上传（单份/目录）与外部平台导入（现有 `ingest_*`）

  * 筛选与报告：

    * 一对一匹配（`/match`）、批量匹配（本地或`/match`迭代）

    * 三级漏斗（`/filter`）、决策与分数线（`/decision`、`/decision_batch`）

    * 可视化报告（雷达/饼图）与导出（CSV/Excel）

  * 后续动作：面试题生成（新增接口或沿用 `llm_enabled` 联动）、名单导出

* 牛人（找工作）

  * 简历制作与优化（新增：简历解析优化接口）

  * 智能岗位推荐（新增：基于特征向量 Top N 推荐接口，或复用 `/filter` 与 `/decision`）

  * 面试准备：基于JD/推荐岗位生成题库（新增接口）

* Admin（监控与运维）

  * 流程监控：数据预处理、模型特征提取、训练/测试（新增监控页，读取日志/统计）

  * 配置管理：行业模板、匹配权重（现有）、LLM开关（现有）

## 后端补充接口（拟新增）

* `POST /jd_generate`：输入自然语言描述，返回结构化JD（岗位名/职责/要求）；封装至 `modules/llm_utils.py`

* `POST /resume_optimize`：输入简历文本或解析结果，返回优化建议与结构化画像；封装至 `modules/llm_utils.py`

* `POST /interview_questions`：输入候选画像或JD，返回题目列表；可与决策页联动（面试题写入推荐）

* `POST /recommend_jobs`：输入候选画像，返回Top N岗位（基于`/filter`或轻量推荐器）

* `POST /feedback_save`（可选）：面试官评价入库；也可复用现有 `/uploads` 写入 JSON

## 前端实现要点

* 侧栏：角色选择置顶；API地址自动检测并回退（已增强）

* 页面集：按角色动态生成 tabs（已实现基础分组），补齐：

  * HR/BOSS：

    * JD智能生成页（输入自然语言，展示结构化JD与导出）

    * 简历来源页（上传、目录扫描、外部平台采集）

    * 匹配/漏斗/决策页强化导出与图表

  * 牛人：

    * 简历优化页（上传与优化报告）

    * 岗位推荐页（Top N 列表 + 可视化 + 导出）

    * 面试题训练页（题库生成与练习记录下载）

  * Admin：

    * 流程监控页（预处理/训练/测试指标展示与图表）

    * 配置编辑页（行业模板与权重，调用现有接口）

* 下载与导出：维持 CSV/Excel 两套；优先使用 xlsxwriter 存在时输出 Excel

## 数据与格式支持

* 扩展 `scripts/02_data_preprocess.py`：图片/OCR（如 `pytesseract`）、表格（如 `pdfplumber`）、扫描件容错；在 `requirements.txt` 中标记可选依赖

* 解析统一输出画像结构（skills/degree/years/position/keywords等），与匹配模型权重一致（`config/matching.json`）

## 权限与安全

* 角色与权限继续基于后端（`TOKEN_ROLE/ROLE_PERMS`），前端仅做可见性裁剪

* 敏感接口（配置写入、索引写入、采集）继续校验权限；候选人仅允许上传

* 不在仓库记录令牌；避免日志写敏感字段
