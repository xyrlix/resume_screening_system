## 🎯 管理员角色完整流程设计

```mermaid
graph TD
A[管理员登录] --> B[模型训练控制台]

B --> B1[1. 数据准备]
B1 --> B1a[选择简历数据目录<br/>（如 /data/resumes/）]
B1 --> B1b[选择JD数据目录<br/>（如 /data/jds/）]
B1 --> B1c[上传标注文件<br/>（CSV格式：resume_id, jd_id, label=0/1）]

B1 --> B2[2. 数据预处理]
B2 --> B2a[自动执行：<br/>- 文本清洗<br/>- 缺失值填充<br/>- 时间对齐<br/>- 异常值剔除]
B2 --> B2b[界面展示：<br/>- 原始样本数 vs 清洗后样本数<br/>- 正负样本比例]

B2 --> B3[3. 特征提取]
B3 --> B3a[结构化特征：<br/>学历、工龄、技能数量等]
B3 --> B3b[语义特征：<br/>使用 BGE-M3 提取 1024 维稠密向量]
B3 --> B3c[界面展示：<br/>- 特征维度<br/>- 向量示例（前5维）]

B3 --> B4[4. 模型训练]

B4 --> B4b[设置参数：<br/>学习率=0.1, 树数量=100]
B4 --> B4c[启动训练]
B4 --> B4d[实时显示：<br/>- 训练进度<br/>- Loss 曲线<br/>- 验证集 AUC 变化]

B4 --> B5[5. 模型评估]
B5 --> B5a[核心指标展示（动态计算）：<br/>- Accuracy: 以标注集与当前模型实时计算<br/>- Precision/Recall/F1: 实时生成<br/>- AUC: 实时生成]
B5 --> B5b[混淆矩阵可视化：<br/>（热力图：TP/FP/TN/FN）]
B5 --> B5c[过拟合检查：<br/>“训练AUC=0.95，验证AUC=0.91 → 无严重过拟合”]
B5 --> B5d[生成评估报告 PDF（可下载）]

B5 --> B6[6. 模型保存与启用]
B6 --> B6a[点击“保存模型”]
B6 --> B6b[系统提示：<br/>“模型已保存为 match_model_v1.pkl”]
B6 --> B6c[自动启用该模型<br/>→ 招聘方 & 求职者端立即使用]

B6 --> B7[7. 效果演示（关键！）]
B7 --> B7a[管理员可手动输入：<br/>- 一份简历文本<br/>- 一份JD文本]
B7 --> B7b[点击“预测匹配度”]
B7 --> B7c[输出：<br/>- 匹配分数：0.87<br/>- 判断：高匹配<br/>- 关键匹配点：<br/>  • “均有‘高并发系统’经验”<br/>  • “技能重合度：Python, Kafka, Redis”]
```

## ✅ 总结：管理员角色的核心价值

### 🎯 一句话核心价值：
> **通过可视化界面，让管理员快速训练并验证一个高准确率的简历-JD匹配模型，并立即服务于招聘方与求职者。**

### 分点价值阐述：

1. **降低AI使用门槛**  
   无需写代码，点击按钮即可完成模型训练，适合非算法背景人员操作。

2. **强调模型可信度**  
   通过 AUC、混淆矩阵、过拟合检测等专业指标，证明模型不是“玩具”，而是**可落地的解决方案**。

3. **打通训练与应用**  
   模型训练完成后自动启用，**招聘方筛选简历、求职者接收推荐**均使用该模型，体现系统一致性。

4. **支持教学演示**  
   所有中间步骤（清洗、特征、训练曲线）均可展示，完美契合课程对“过程透明”的要求。

5. **聚焦核心问题**  
   不堆砌复杂功能，只解决“如何训练一个好模型并证明它有效”这一本质问题。
